一个把赛车资讯与天气放在一起的个人主页

这个站点在做什么

把两类信息放在一屏里：

赛车资讯 —— 直接抓取 The Race 的 RSS、F1 官网的最新页、倍耐力新闻室的 Formula 1 分类，抓标题、缩略图、摘要、发布时间和原文链接，标题附中文译文。

赛道天气 —— 赛历来自 F1 官方页面，比赛周末的逐日天气取自 Open-Meteo，已结束的分站显示历史实测值，正在逼近的分站显示逐日预报，同时给出赛道的当前实况、空气质量与紫外线强度。

所有内容在浏览器里实时抓取，没有中间服务器，也不需要任何 API Key。

怎么改

所有可调项都在 assets/config.js：姓名简介、订阅源、天气城市、代理地址。改完刷新页面即可。

抓取走公共 CORS 代理，这类服务经常抽风。真跑不动了，把自己的代理地址填进 fetch.proxies 即可。
